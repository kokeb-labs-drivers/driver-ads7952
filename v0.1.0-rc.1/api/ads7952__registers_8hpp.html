Detailed Description

ADS795x command and reply words: the bit fields of every frame (datasheet SLAS605C, section 8.4 and 8.5, Tables 1 to 13).

The chip has no addressable registers. Every frame is one 16-bit word on SDI, MSB first, with CS low for exactly 16 SCLK cycles; its top four bits (DI15:12) say what the word is: a mode control word (Manual, Auto-1, Auto-2 or "continue") or the first or only frame of a program register (GPIO, Auto-1 channel mask, Auto-2 last channel, alarm thresholds). At the same time the chip shifts out one 16-bit reply on SDO: a 4-bit channel address (or the GPIO levels) in DO15:12 and the 12-bit conversion result in DO11:00.

Everything here is constexpr masks and shifts; there are no bit-field unions, whose layout depends on the compiler.
