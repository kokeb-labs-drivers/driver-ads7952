Detailed Description

Optional ESP-IDF layer: a Config built from the CONFIG_ADS7952_* Kconfig options.

Copyright
Copyright (c) 2026 The driver-ads7952 authors. SPDX-License-Identifier: MIT

Include this header only where you want menuconfig to choose the defaults; the driver never includes it and no driver signature depends on it. Under ESP-IDF the values come from sdkconfig.h. Without Kconfig every option falls back to the reset state of the chosen part, so KconfigDefaults() equals Config{}.

Kconfig writes a bool option set to "n" as an absent macro, so an absent CONFIG_ADS7952_RANGE_2VREF means Range 1 in both cases. GPIO and alarm settings are not Kconfig options: set them in the Config in code.

One configuration per program: the inline function below depends on the CONFIG_ macros, so every translation unit of one program must see the same values (ESP-IDF has one sdkconfig.h per build; each host test is its own program). No driver header includes this one (handbook KB-CPP20-018).
