Detailed Description

ADS7952 driver: the one header to include.

Copyright
Copyright (c) 2026 The driver-ads7952 authors. SPDX-License-Identifier: MIT

ads7952::ADS7952<Port> drives one ADS7950, ADS7951, ADS7952 or ADS7953 12-bit SAR ADC through a platform port you write (see ads7952_spi_interface.hpp). The driver has no platform code, allocates nothing, throws nothing, takes no lock and is not thread-safe: give each object one owner, or guard it with one mutex. Section, table and figure numbers refer to the datasheet, TI SLAS605C (revised July 2018).
