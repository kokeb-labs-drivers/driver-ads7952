# ADS7952 Driver API reference {#mainpage}

The classes, types and registers of the ADS7952 driver, generated from the headers in `inc/`.

Start with ads7952::ADS7952, the driver, and ads7952::SpiInterface, the base of the port you write. Errors are
ads7952::Error inside ads7952::Result; the configuration is ads7952::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">ADS7952 Driver
documentation</a>.
